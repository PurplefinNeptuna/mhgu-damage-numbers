# Validation scope

Host tests exercise copied-value capture nesting, scope overflow/quarantine, ownership/source policy, bounce association, bounded model/mailbox overflow, duplicate suppression, disabled settings, sprite decoding, concurrent publication and queued records surviving thread exit.

The config harness compiles the pinned upstream config/INI modules and derives, plus production src/config.rs, against test MtFile and counted-mount I/O. It checks automatic default-file creation, individual defaults and invalid parsing, all style round trips, Save and Reset.

The hook harness compiles production src/hooks.rs and the stock Patch wrapper against a native API double. Failures are injected before and after branch publication at all eight sites and during each cache synchronization. All originals must be restored and capture must remain disabled. Success activates all eight.

The C++ r25 oracle comparison covers 243 combinations of style, critical outcome, HZV and age, producing 1,944 draw records. Exact identities/colors/text and bounded float differences are checked. Another 2,800 cases compare source/owner policy, finalized damage/critical outcomes and native matrix projection against r25, including invalid matrices, perspective, translation and clipped points. The real renderer harness compiles production src/render.rs with pinned Forge font/draw wrappers and actual ImGui 1.92.8. All three styles at three ages are compared at 1920×1080, including textures, glyph atlas bytes, draw commands, indices, vertices and composited pixels. Repeated initialization is checked against duplicate resource creation.

The ARM fixture executes all nine gateways from the production NRO in Unicorn 2.1.4. Its helper doubles deliberately clobber registers, floating-point state and flags; it checks all GPRs, d0–d31, FPSCR, NZCVQ, LR/SP, native stack arguments, around-return paths, and all 16 GE patterns with preserved and changed GE. Helpers are doubles; this is not a native gameplay run. The eight-site GE liveness audit applies to the pinned game and unchanged gateway sites.

`verify` additionally compares compiler-derived Rust/C++ ARM32 Hook, saved frame, ImGui/font/texture/draw layouts; checks callback exports, all strong imports against actual main/SDK/Forge exports, exact game signatures, asset receipt hashes and nine NZCVQ-only restoration instructions.

Gameplay, config persistence across a real restart, loader allocation limits and emulator lifecycle remain manual checks. No installation, activation or game launch is performed by these commands.
