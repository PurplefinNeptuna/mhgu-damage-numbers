# Pinned development inputs

forge-rs is vendored at `d1865b68e9b194eb3eacc8bd71bbf601a5fac63e` (MIT, Fexty), version 1.5.0. The vendored workspace omits cargo-forge from its member list. The 1.4.1 converter is supplied separately and fingerprinted. Local adjustments retain the ImGui DrawList c_char pointer casts and change the entry macro to leave the loader requirement record untouched and declare the native zero-argument init callback. The upstream 24-byte Hook binding is used unchanged. Config/TLS/singleton/Patch/font helpers retain upstream behavior. Native field offsets and imports are checked against the copied 1.5.0 loader input.

Cargo.lock pins runtime/procedural-macro dependencies. Their source and license files live in vendor/crates. The additional sysroot packages supply this nightly's full resolver metadata; only core/alloc/compiler_builtins are built into the ARM runtime. `research/sysroot-Cargo.lock` pins that metadata. Two prebuilt WASI-only objects are omitted from wit-bindgen; its vendor file checksum list describes the retained source subset. WASI libraries are not built for this ARM32 plugin. Runtime component notices are separate from these build-only dependencies.

The pinned C++ oracle and the gateway were copied from this workspace's Damage Numbers r25 source baseline at parent commit `6558bd1`. Oracle code exists only in host tests; it is never linked into damage_numbers_rs.nro. The production gateway is byte-identical to the existing audited assembly. Its GE audit and native declarations are retained under research for reproducible validation. ARM SVC wrappers originate in the project's maintained libnx integration, with the ENTRY macro namespaced to avoid assembler collisions.

The host renderer uses pinned ImGui/cimgui 1.92.8 snapshots and their MIT licenses in vendor/cimgui. The prepared font originated from Open Sans at Google Fonts revision `9710da1eacb3be272583c3224dcb70f9da6eadbb` and the Forge/Roboto Medium reference for matching metrics. Font licenses and input hashes are preserved. Roboto and the host renderer are development inputs; the runtime ships the prepared Open Sans Semibold subset and two external procedural RGBA files. Font naming metadata was restored without changing outlines, hinting or metrics. Their current hashes and provenance are in assets/manifest.json.

The new Rust implementation, fixtures, recipes and explanatory documentation were written with OpenAI Codex assistance. Procedural artwork retains the prepared pixels from the previous authored generation recipes; this is code assistance, with no model-generated image or audio asset. The explicit platform disclosure is recorded in DISTRIBUTION.json.

The native allocator fixture retains Forge `hook.c` and `hook.h` from revision `1671ad1526f6df5ee8d6e61a03518e0a427e202e`, with their MIT copyright/license text. It is development-only and is not linked into the NRO. The fixture substitutes host platform operations and omits the two ARM barriers while keeping allocator and branch construction source unchanged.

The frozen C++ asset headers and decoder are test-only reference inputs. The 24 r2 golden images and atlas hashes were captured from production renderer source at `9aebd26` before changing its asset-loading or drawing implementation. They contain generated test scenes and licensed font/artwork pixels, not game captures.
